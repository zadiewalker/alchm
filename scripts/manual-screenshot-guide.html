🚀 Quick Start Instructions

1. Start Your Development Server

Open terminal and run: npm run dev

Verify ALCHM loads at: http://localhost:3000

2. Open Browser Developer Tools

Press F12 or Cmd+Option+I (Mac) / Ctrl+Shift+I (Windows)

Click the device toggle icon (📱) to enable mobile simulation

3. Select Device Sizes

Use the dropdown to select each required device size and take screenshots

🎨 Screenshot Quality Checklist

📸 How to Take Screenshots

Method 1: Browser Developer Tools
  1. Open developer tools (F12)
  2. Enable device simulation (📱 icon)
  3. Select device size from dropdown
  4. Navigate to page URL
  5. Right-click → "Capture screenshot" or use screenshot menu
Method 2: Manual Resize
  1. Resize browser window to exact pixel dimensions
  2. Navigate to page
  3. Use system screenshot tool (Cmd+Shift+4 on Mac, Snipping Tool on Windows)
  4. Crop to exact size if needed
Method 3: Browser Extensions
  1. Install "Full Page Screen Capture" or similar extension
  2. Navigate to page
  3. Use extension to capture at specific dimensions

💾 File Naming Convention

Save screenshots with this naming pattern:

alchm_[page]_[device]_[size].png

Examples:
• alchm_landing_iphone67_1290x2796.png
• alchm_login_android_1080x1920.png
• alchm_journal_ipad_2048x2732.png
