# ALCHM Sacred Component Naming Guide

This guide documents the transformation of ALCHM's component library from technical abstractions to sacred, ritual-based semantics that align with our soul-based UX architecture.

## Sacred Naming Philosophy

Components in ALCHM are not mere UI elements - they are **emotional containers**, **ritual spaces**, and **ceremonial tools** for human flourishing. Each component name should evoke the spiritual and emotional function it serves.

### Core Sacred Semantics

**Transformation Principle**: Technical → Ritual → Emotional Container

## Implementation Strategy

### Phase 1: Core Foundation Renames
1. **Layout System**: `SanctuaryShell`, `CrownChakra`, `GroundingRoots`
2. **Modal/Dialog**: `RitualGate`, `HeartConversation`
3. **Basic Interactions**: `IntentionGem` (Button), `VoiceChannel` (Input)

### Phase 2: Journey Components
1. **Journal System**: `ReflectionCard`, `SoulCanvas`, `WisdomMirror`
2. **Navigation**: `PathwayCompass`, `ChapterGateway`, `SacredTrail`
3. **Progress Tracking**: `GrowthThread`, `SacredSeasons`

### Phase 3: Community & AI
1. **AI Components**: `KheperaOracle`, `InvitationChalice`, `WisdomGate`
2. **Community**: `WitnessingCircle`, `TribalGathering`, `SoulPortrait`
3. **Specialized Tools**: All remaining emotional and healing components

## Sacred Naming Principles

### 1. Emotional Resonance
Names should evoke the **feeling** the component creates, not just its function.

### 2. Ritual Context
Each component exists within the **ceremony of healing** - name it for its ceremonial role.

### 3. Cultural Wisdom
Draw from **universal spiritual traditions** while remaining respectful and inclusive.

### 4. Poetic Language
Use **metaphor and symbolism** that speaks to the soul, not just the mind.

### 5. Trauma-Informed Naming
All names should feel **safe, gentle, and empowering** - never clinical or pathologizing.
