# ALCHM iOS App Icons

## Overview
This directory contains all required iOS app icons generated from the master SVG design.
Icons are compliant with Apple App Store Guidelines and maintain ALCHM's trauma-informed brand identity.

## Brand Identity
- **Primary Color**: Sage Green (#a4b792) - representing healing and growth
- **Background**: Sanctuary White (#f7f7f2) - creating safe space
- **Symbol**: Scarab beetle with healing cross - transformation and trauma-informed care

## Icon Specifications

### Required iOS Sizes
- **1024x1024px**: App Store - App Store listing
- **180x180px**: iPhone App (3x) - iPhone home screen @3x
- **120x120px**: iPhone App (2x) - iPhone home screen @2x
- **167x167px**: iPad Pro App - iPad Pro home screen
- **152x152px**: iPad App (2x) - iPad home screen @2x
- **76x76px**: iPad App (1x) - iPad home screen @1x
- **60x60px**: iPhone Spotlight (3x) - iPhone spotlight @3x
- **40x40px**: iPhone Spotlight (2x) - iPhone spotlight @2x
- **58x58px**: iPhone Settings (2x) - iPhone settings @2x
- **29x29px**: iPhone Settings (1x) - iPhone settings @1x
- **87x87px**: iPhone Settings (3x) - iPhone settings @3x

### Optional Sizes (for completeness)
- **20x20px**: iPhone Notification (1x) - iPhone notifications @1x
- **80x80px**: iPad Spotlight (2x) - iPad spotlight @2x

## Design Principles
1. **App Store Compliance**: No transparency, no rounded corners (iOS adds automatically)
2. **Trauma-Informed**: Calming sage palette, healing symbols
3. **Clarity**: Sharp and recognizable at all sizes
4. **Brand Consistency**: Maintains ALCHM's sacred geometry and color identity

## File Generation
Icons are generated programmatically using the generate-ios-icons.js script.
This ensures consistency and compliance across all required sizes.

## App Store Connect Configuration
Use the generated icons in the following contexts:
- App Store listing (1024x1024)
- iOS home screen display
- Spotlight search results
- Settings app display
- Notification badges
