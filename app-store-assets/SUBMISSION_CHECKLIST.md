# ALCHM App Store Submission Checklist

## Pre-Submission Requirements

### 1. Assets
- [ ] App Icon (1024x1024 PNG, no transparency)
- [ ] iPhone 6.7" Screenshots (3-10 images, 1290x2796)
- [ ] iPhone 6.5" Screenshots (3-10 images, 1284x2778)  
- [ ] iPhone 5.5" Screenshots (3-10 images, 1242x2208)
- [ ] iPad Screenshots (3-10 each: 2048x2732, 1668x2388)
- [ ] App Preview Video (optional, 30s max)

### 2. Legal & Compliance
- [ ] Privacy Policy published and accessible
- [ ] Terms of Service published and accessible
- [ ] Support contact information available
- [ ] Age rating assessment completed (17+)
- [ ] Content rating questionnaire answers prepared

### 3. App Store Connect Setup
- [ ] Developer account in good standing
- [ ] App created in App Store Connect
- [ ] Bundle ID configured (com.alchm.app)
- [ ] Pricing set (Free with optional subscriptions)
- [ ] Availability/territories selected

### 4. Technical Requirements
- [ ] PWA converted to iOS app (using PWABuilder or Capacitor)
- [ ] App compiled and tested in Xcode
- [ ] App submission build uploaded via Xcode/Transporter
- [ ] All features tested on physical iOS devices

### 5. Metadata
- [ ] App name and subtitle finalized
- [ ] App description written (under 4000 chars)
- [ ] Keywords selected (under 100 chars total)
- [ ] Promotional text written (under 170 chars)
- [ ] What's New text prepared

### 6. Review Preparation  
- [ ] Demo account created for reviewers
- [ ] Review notes written explaining app functionality
- [ ] Crisis support features documented
- [ ] Mental health disclaimers prominently displayed
- [ ] All app features functional and tested

### 7. Privacy & Data
- [ ] Privacy nutrition label completed in App Store Connect
- [ ] Data collection practices disclosed
- [ ] Encryption implementation documented
- [ ] Third-party service usage declared (Firebase, Anthropic)

## Submission Process

1. **Upload Build**
   - Compile app in Xcode
   - Archive for distribution
   - Upload via Xcode Organizer or Transporter

2. **Complete Metadata**
   - Add all screenshots
   - Write descriptions and keywords  
   - Set pricing and availability
   - Complete privacy questionnaire

3. **Submit for Review**
   - Add review notes
   - Submit for App Review
   - Monitor status in App Store Connect

## Timeline Estimate
- Asset creation: 1-2 weeks
- PWA conversion: 1 week  
- App Store setup: 2-3 days
- Review process: 1-7 days (Apple standard)
