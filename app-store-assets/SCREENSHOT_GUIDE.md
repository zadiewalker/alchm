## Screenshot Generation Process:

### Method 1: iOS Simulator (Recommended)
1. Open iOS Simulator with required device size
2. Navigate to https://alchmapp.web.app
3. Interact with key features
4. Use Cmd+S to capture screenshots
5. Crop to exact required dimensions

### Method 2: Device Screenshots
1. Use physical iPhone/iPad
2. Take screenshots with device buttons
3. AirDrop to Mac for processing
4. Resize to exact App Store requirements

### Method 3: Browser Dev Tools
1. Open Chrome Dev Tools
2. Set device emulation to required size
3. Navigate through app features
4. Use browser screenshot tools
5. Crop and export to required dimensions

## Quality Guidelines:
- High resolution, crisp images
- Show actual app content (no mockups)
- Consistent lighting and contrast
- No status bar modifications
- Real or realistic data content
- Focus on key differentiating features
