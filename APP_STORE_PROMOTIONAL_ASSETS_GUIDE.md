## 🛠 Asset Creation Workflow

### Step 1: Set Up Photoshop Templates
```
For each asset:
1. Create new Photoshop document with exact dimensions
2. Set resolution to 300 DPI for high quality
3. Color mode: RGB
4. Background: Transparent or white
5. Save as PSD format
```

### Step 2: Create Smart Objects
```
For each design element:
1. Import as Smart Object (not linked)
2. Embed all fonts and images
3. Use layer groups for organization
4. Name layers descriptively
5. Keep all elements editable
```

### Step 3: Content Creation
```
Text Elements:
• Headlines in SF Pro Display Light
• Body text in SF Pro Text Regular  
• Maintain hierarchy and readability
• Use ALCHM brand voice (gentle, safe, empowering)

Visual Elements:
• iPhone mockups showing real app interface
• ALCHM scarab beetle icon
• Sage green color palette
• Subtle gradients and shadows
• Generous whitespace
```

### Step 4: Quality Control
```
Before submission:
□ All dimensions exactly match requirements
□ All elements are Smart Objects (embedded, not linked)
□ Text is crisp and readable at all sizes
□ Colors match ALCHM brand palette
□ No spelling or grammar errors
□ File size under 500 MB preferred
□ Proper naming convention used
```
