## 🆘 TROUBLESHOOTING GUIDE

### 🚨 If Deployment Fails

#### Build Error Scenarios:
```bash
# Run our diagnostic first
node scripts/quick-firebase-studio-check.js

# If issues found, run comprehensive audit
node scripts/firebase-studio-diagnostic.js
```

#### Common Issues & Fixes:
1. **ES Module Error**: Re-run `rm next.config.mjs` and verify CommonJS usage
2. **Runtime Error**: Confirm Node.js 20 in `apphosting.yaml`
3. **Build Timeout**: Check for dependency conflicts
4. **Missing Assets**: Verify static asset copying in build

#### Emergency Rollback:
```bash
# Previous working configuration
git checkout HEAD~1 apphosting.yaml next.config.js
```
