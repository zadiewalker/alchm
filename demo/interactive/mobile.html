🧠 Trauma-Informed Design

Gentle Visual Hierarchy

Soft gradients, rounded corners, and calming colors reduce visual stress and create a sense of safety.

Predictable Interactions

Consistent navigation patterns and clear feedback help users feel in control and reduce anxiety.

Emotional Regulation Tools

Built-in grounding techniques and breathing exercises are always accessible for crisis moments.

Privacy-First Interface

No identifying information visible on screen, with quick hide/exit options for safety.

🚨 Crisis Mode Features

Instant Access

One-tap access to crisis resources from anywhere in the app, with no navigation barriers.

Immediate Grounding

Interactive grounding exercises help users stay present and manage overwhelming emotions.

Emergency Contacts

Pre-loaded crisis hotlines with one-tap calling and location-based emergency services.

Safety Planning

Personalized safety plans created during stable periods, accessible during crisis moments.

📡 Offline Support

Critical Resource Caching

Crisis hotlines, breathing exercises, and safety tools cached locally for offline access.

Offline Journaling

Continue journaling without internet connection, with automatic sync when connection returns.

Progressive Web App

Native app-like experience that works reliably even with poor network conditions.

Smart Sync

Intelligent synchronization minimizes data usage while ensuring critical updates are prioritized.

♿ Accessibility Excellence

WCAG 2.1 AAA Compliance

Exceeds accessibility standards with high contrast ratios and semantic HTML structure.

Screen Reader Optimization

Comprehensive ARIA labels and logical reading order for visually impaired users.

Motor Accessibility

Large touch targets, voice navigation, and switch control support for users with motor impairments.

Cognitive Accessibility

Simplified language, clear instructions, and reduced cognitive load for users with cognitive differences.
