# App Store Data Safety Report
## ALCHM - Trauma-Informed Journaling Platform

### Data Collection Summary

#### Personal Information Collected
- **User Accounts**: Email address, display name, age verification
- **Journal Content**: User-written text entries (encrypted at rest)
- **Emotional Data**: Mood ratings, wellness tracking metrics
- **Crisis Information**: Emergency contact details for users under 18

#### Technical Data Collected
- **Device Information**: Device type, OS version, app version
- **Usage Analytics**: Feature usage patterns (anonymized)
- **Performance Data**: Crash reports, error logs, loading times
- **Location Data**: General location (country/state) for crisis resource routing

#### AI Processing Data
- **Content Analysis**: Journal text processed by Google Gemini AI
- **Processing Purpose**: Generate supportive insights and crisis detection
- **Data Retention**: AI processing data deleted within 24 hours
- **Third-Party Integration**: Google Cloud Platform and Firebase services

### Data Usage Categories

#### Primary Service Provision
- **Journaling Platform**: Secure storage and retrieval of user journal entries
- **AI Insights**: Generate personalized reflections and growth suggestions
- **Progress Tracking**: Monitor emotional wellness trends and patterns
- **Crisis Detection**: Automated identification of potential safety concerns

#### Safety and Security
- **Crisis Intervention**: Emergency response for users expressing suicidal ideation
- **Account Security**: Authentication and access control
- **Platform Security**: Fraud prevention and abuse detection
- **Data Protection**: Encryption and security monitoring

#### Service Improvement
- **Analytics**: Understand user behavior to improve platform (anonymized data only)
- **Performance Monitoring**: Track app performance and fix technical issues
- **Feature Development**: Develop new features based on user needs
- **Quality Assurance**: Test new features and ensure platform stability

### Data Sharing and Third Parties

#### Google Services (Required for Core Functionality)
- **Firebase Authentication**: User account management and login
- **Firebase Firestore**: Encrypted database storage for journal entries
- **Firebase Cloud Functions**: Server-side processing for AI insights
- **Google Gemini AI**: Natural language processing for journal analysis
- **Data Processing Agreement**: Standard contractual clauses with Google

#### Crisis Intervention Services
- **Emergency Services**: Local 911 dispatch when imminent danger detected
- **Crisis Hotlines**: Integration with national suicide prevention lifeline
- **Mental Health Referrals**: Connection to local mental health professionals
- **Parental Notification**: Emergency contacts for users under 18

#### Payment Processing (Premium Features Only)
- **Stripe**: Secure payment processing for subscription services
- **Data Shared**: Payment information, subscription status
- **PCI Compliance**: Industry-standard payment security protocols
- **Data Retention**: Financial records retained per legal requirements

#### Legal and Compliance
- **Law Enforcement**: Only when required by valid legal process
- **Child Protection**: Reports to authorities when child abuse suspected
- **Regulatory Compliance**: Data shared to comply with COPPA, GDPR
- **Legal Proceedings**: Court-ordered disclosure when legally required

### User Control and Rights

#### Data Access and Control
- **View Personal Data**: Users can request copies of all personal information
- **Correct Information**: Update or modify account information anytime
- **Delete Account**: Permanently remove account and all associated data
- **Export Data**: Download journal entries and mood tracking data
- **Privacy Settings**: Control data sharing and analytics participation

#### Parental Controls (Users Under 18)
- **Account Oversight**: Parents can review account settings (not journal content)
- **Privacy Controls**: Manage child's data sharing preferences
- **Crisis Notifications**: Receive alerts for crisis interventions
- **Account Termination**: Delete child's account and all data
- **Consent Management**: Withdraw consent for data processing

#### GDPR Rights (EU Users)
- **Right to Access**: Obtain copy of personal data held by ALCHM
- **Right to Rectification**: Correct inaccurate personal information
- **Right to Erasure**: "Right to be forgotten" data deletion
- **Right to Portability**: Transfer data to another service provider
- **Right to Object**: Opt-out of automated decision-making

### Security Measures

#### Data Protection
- **Encryption at Rest**: AES-256 encryption for all stored data
- **Encryption in Transit**: TLS 1.3 for all data transmission
- **Access Controls**: Multi-factor authentication for staff access
- **Regular Audits**: Quarterly security assessments and penetration testing
- **Incident Response**: 24-hour breach notification protocol

#### Privacy Safeguards
- **Data Minimization**: Collect only information necessary for service provision
- **Purpose Limitation**: Use data only for stated purposes
- **Storage Limitation**: Delete data when no longer needed
- **Anonymization**: Remove personally identifiable information from analytics
- **Pseudonymization**: Replace identifying fields with artificial identifiers

#### Crisis Data Protection
- **Privacy-Preserving Detection**: Use AI summaries, not raw journal content
- **Secure Storage**: Crisis assessment data encrypted and access-controlled
- **Retention Limits**: Crisis data deleted within 7 days (except safety records)
- **Professional Standards**: Crisis counselors bound by confidentiality agreements
- **Audit Trails**: Crisis interventions logged for safety improvement

### Age-Specific Protections

#### Children Under 13 (COPPA Compliance)
- **Parental Consent**: Verifiable parental consent required before data collection
- **Limited Collection**: Minimal data collection necessary for service provision
- **No Third-Party Sharing**: Personal information not shared with third parties
- **Parental Rights**: Parents can review, modify, or delete child's information
- **Safe Harbor**: Comply with COPPA safe harbor provisions

#### Teens 13-17 (Enhanced Protections)
- **Privacy by Default**: Strictest privacy settings enabled by default
- **Parental Notification**: Parents notified of account creation (optional oversight)
- **Crisis Protocols**: Enhanced crisis intervention with parental notification
- **Educational Focus**: Platform designed for emotional learning, not therapy
- **Professional Referrals**: Encourage ongoing professional mental health support

### International Data Transfers

#### Transfer Mechanisms
- **Adequacy Decisions**: Transfers only to countries with adequate data protection
- **Standard Contractual Clauses**: EU-approved transfer mechanisms
- **Binding Corporate Rules**: Internal policies governing international transfers
- **User Consent**: Explicit consent for transfers outside user's country

#### Processing Locations
- **Primary Storage**: United States (Google Firebase servers)
- **AI Processing**: Google Cloud Platform global infrastructure
- **Backup Storage**: Encrypted replicas in Canada and EU
- **Crisis Services**: Local processing for emergency response coordination

### Retention and Deletion

#### Data Retention Periods
- **Journal Entries**: Retained until user deletion or account closure
- **Account Information**: Deleted 30 days after account closure
- **Analytics Data**: Anonymized data retained maximum 2 years
- **Crisis Records**: Safety documentation retained 7 years (legal requirement)
- **Payment Data**: Financial records retained per regulatory requirements

#### Secure Deletion Process
- **User-Initiated**: Immediate deletion available through account settings
- **Verification Required**: Email confirmation for account deletion
- **Complete Removal**: Data removed from all systems including backups
- **Third-Party Notification**: Service providers notified to delete shared data
- **Audit Documentation**: Deletion activities logged for compliance verification
