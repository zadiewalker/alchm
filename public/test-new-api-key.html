🔑 Firebase API Key Tester

Test different Firebase API keys to find one that works for Google authentication.

📋 Step-by-Step Process:

  1. Go to Firebase Console
  2. Select project: alchm-digital-sanctuary
  3. Go to Project Settings (gear icon) → General tab
  4. Find "Your apps" section → Web apps
  5. Copy the apiKey value and paste it below

The current API key from your .env.local is pre-filled above. Click "Test This API Key" to see if it works, or get a new one from Firebase Console.
