## Design Requirements

### Color Palette
- **Primary**: Sage greens (#a4b792, #93a682, #82956f)
- **Accent**: Warm whites and soft golds
- **Crisis**: Professional reds for emergency elements
- **Text**: High contrast for accessibility

### Typography
- **Headers**: Clean, modern sans-serif
- **Body**: Highly readable, WCAG AA compliant
- **Crisis Text**: Bold, clear emergency styling

### Accessibility Requirements
- **Contrast Ratio**: Minimum 4.5:1 for normal text, 3:1 for large text
- **Text Size**: Minimum 16pt for body text in screenshots
- **Color Independence**: Information not conveyed by color alone
- **Screen Reader**: Alt text prepared for all visual elements

### Safety & Compliance Elements
- **Age Rating**: "17+" prominently displayed
- **Medical Disclaimer**: "Not Medical Treatment" visible
- **Crisis Resources**: "988 Crisis Support" shown
- **Privacy**: "Your Data Stays Private" messaging

## Technical Specifications

### File Requirements
- Format: PNG (24-bit) or JPEG (high quality)
- Color Space: sRGB
- Maximum file size: 8MB per screenshot
- No transparency or alpha channels

### Content Guidelines
- **No real user data** in screenshots
- **Mock content only** that represents typical use
- **Professional medical disclaimers** visible
- **Crisis resources prominently shown**
- **Cultural sensitivity** in all imagery
- **Accessibility considerations** in design

### Localization
- Primary language: English
- Future: Spanish, Portuguese versions for relevant markets
- Cultural imagery appropriate for diverse users
